# Client — Smart Daily Standup Bot

The Angular frontend. Generated with Angular CLI 19.2.5 (NgModules, not standalone).

**Documentation lives at the repository root:**

- [`../README.md`](../README.md) — project reference: stack, API, architecture, assumptions
- [`../HANDOVER.md`](../HANDOVER.md) — setup walkthrough, troubleshooting, end-to-end flow

## Quick start

This app needs the API running on <http://localhost:3000> — start `server/` first.

```bash
npm install
npm start        # http://localhost:4200
```

## Scripts

| Command | Purpose |
|---|---|
| `npm start` | Dev server with live reload |
| `npm run build` | Production bundle into `dist/` |
| `npm test` | **No specs exist** — see the testing note in `../HANDOVER.md` |

The API base URL is set per environment in `src/environments/`.
